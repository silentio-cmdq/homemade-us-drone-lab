# CAD and print files

Drop STLs and STEP files here, grouped by setup:

```
cad/
  whoop75/
  toothpick35/
  five_inch_tpu/
  fixtures/
```

Filename pattern:

```
whoop75_frame_petg_v3_11g.stl
```

Include a one-line `NOTES.md` in each subfolder: material, layer height, mass as printed, source (original / remixed / URL).

Do not commit slicer cache or 200 MB binary project files.
