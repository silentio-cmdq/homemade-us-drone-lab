# Setup 02 assembly and ops

1. Dry-fit carbon + printed parts. Countersink screw heads that sit under a pack.
2. Build the stack with the shortest power wires you can solder cleanly.
3. Antenna: keep 5.8 GHz away from the carbon sandwich. Printed standoff helps.
4. CG: battery so the aircraft hangs level from the FC.
5. Tune outdoors in Angle first, then Horizon, then Acro.
6. Land at 3.5 V/cell. Packs that stay in the bag last longer than packs that make one more lap.
7. If AUW ≥ 250 g: stop, register, mark, add Remote ID before the next outdoor pack.
