# Setup 02 — 3 / 3.5" outdoor quad under 0.5 lb

**Role:** first outdoor homemade aircraft that still tries to stay under 226.8 g AUW.

**Hard rule:** weigh before every new camera. A "tiny" HD camera is how this build becomes a registered aircraft by accident.

## Mass budget (grams)

| Group | Budget |
| --- | --- |
| Frame (carbon plates + printed canopy/tray) | 30–45 |
| Motors ×4 | 40–55 |
| FC + 4-in-1 ESC or AIO | 10–18 |
| RX + GPS (GPS optional, expensive in grams) | 2–18 |
| Camera + VTX + antenna | 8–25 |
| Hardware, wires, pads | 8–12 |
| Battery 3S/4S 650–1100 mAh | 60–95 |
| **Total** | **≤ 220 preferred / 227 hard** |

If the sum is 240 g, remove GPS or the HD cam. Do not "hope the scale is wrong."

## Suggested architecture

- 3.5" carbon plates (1.5 mm top/bottom) + printed TPU camera pod.
- 1404 or 1506 motors if the budget allows; 1103/1202.5 if you are starving grams.
- 20×20 stack or 25.5 AIO.
- Analog or a documented lite digital system. No full-size action cam on this airframe if 0.5 lb is the point.

US-content on this size is still thin. Use the Stage 3 stack if a 20×20 US FC appears in stock; otherwise fly the imported micro stack and keep the printed parts + radio + process American.

## Radio and charger

Same ELRS radio as Setup 01. 3S/4S charger profile, storage charge after the session.
